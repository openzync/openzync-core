Move `get_queue_name` out of the worker package. The queue-name builder lived in `services/worker/worker_settings.py` but was imported by API-side modules (`services/metrics_service.py`, `services/user_summary_service.py`, `services/memory_service.py`, `services/fact_service.py`, `services/webhook_service.py`, `services/graph_edge_sync_service.py`, `middleware/audit.py`) — the API reaching into the worker package for a label both sides share. It now lives in `core/queue_names.py` and every importer was updated. The label format (`OpenZync:{env}:queue:{high|low}`) is unchanged, so the metrics queries and the Grafana dashboard regex keep matching.
