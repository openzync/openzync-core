Project memory wipe is now org-gated: wiping a project outside the caller's organization (or an archived/missing one) returns 404 instead of deleting by bare `project_id`, and the episode/fact `UPDATE` statements carry an `organization_id` predicate. `CORS_ORIGINS` containing `*` is now a startup error — the API always serves `allow_credentials=True`, under which a wildcard origin is both rejected by browsers and a credential leak where tolerated; list explicit origins instead.
