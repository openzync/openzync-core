Scope RBAC Redis cache keys on `(org_id, user_id)` for roles, permission sets, and the must-change-password flag — a user with roles in two orgs could previously read one org's cached role from another org's lookup. Webhook signing secrets are now encrypted at rest via OpenBao Transit (`WEBHOOK_SECRET_KEY`, AAD = endpoint id): encrypted before create/rotate/update, decrypted only at sign time, with legacy plaintext rows used as-is until rotation; the secret is still never returned by list/get. Fact batch dedup now goes through the atomic `IdempotencyService.claim_content_hash` Lua claim (losers replay the winner's `job_id`) instead of check-then-set. API-key project auth now runs the same org-scoped, archived-excluding project lookup as JWT auth. Committed ingests no longer 500 on context-cache purge or webhook emit failures (log-and-continue; `emit()` never raises by contract), and S3 blobs orphaned by a pre-commit failure are compensated inline while committed rows keep `storage_key` for the orphan-blob GC worker. Hybrid retrieval legs run concurrently on sibling RLS-bound sessions, BM25 legs moved into the episode/fact repositories, graph merge skips ID-less items instead of raising `KeyError`, and `sort=recent` normalizes datetimes/ISO strings/missing values to epoch so mixed shapes never raise `TypeError`. Webhook Transit failures now surface as JSON 502 (`ExternalServiceError`, fail-loud, no plaintext fallback) on both the request path (`_encrypt_secret`) and the Transit layer, with startup failing fast when the `webhook-secret` Transit key is missing. NULL-secret endpoint backfill without Transit skips the endpoint instead of persisting plaintext, and every decrypt/backfill skip is counted on `openzync_webhook_decrypt_skips_total{reason}` for dashboards. Hybrid legs run sequentially on the shared session when no sibling-session factory is available (no `gather` on one `AsyncSession`), and `_scoped()` passes through `org_config`/reranker. `LOW_MAX_WORKERS` floor is now contractually `ge=2`.
