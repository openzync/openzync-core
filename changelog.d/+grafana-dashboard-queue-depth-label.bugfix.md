Match the Grafana overview dashboard's queue-depth PromQL selectors to the label the worker actually emits — the fully qualified queue name (`OpenZync:{env}:queue:{high|low}`) instead of the bare `high`/`low`, which matched no series and left the Grafana queue-depth panels permanently empty. A checked-in dashboard does not know the deployment environment, so the selector uses an anchored regex (`queue_name=~"OpenZync:.*:queue:high"`) that matches the qualified name in any environment.
